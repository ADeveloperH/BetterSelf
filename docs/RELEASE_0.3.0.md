# 0.3.0：计划、知识库与多级页面

日期：2026-10-26。状态：已发布并通过线上复核，等待 Android 实机确认更新。

## 界面结构

手机底部统一为四个主入口：计划、知识、训练、搜索。

- 计划：默认入口。本周计划、24 周行动路线和四类经验案例分别使用独立页面。周任务与案例详情是编辑层，手机端只保留顶部返回。
- 知识：主页只展示知识主题、常用集合、继续阅读和最近整理。主题与集合进入二级页，笔记使用紧凑列表；文章和原文对照进入更深的阅读页。
- 训练：面试练习与待复习合并到同一个主入口，通过页面顶部切换，避免底部导航职责重复。
- 搜索：支持笔记、面试题和经验案例。案例搜索也覆盖当前设备保存的草稿。

所有详情页都记录真实父页面。从 Android 主题打开笔记、从搜索打开案例、从计划打开周任务后，顶部返回会回到实际来源。切换主 Tab 后再次返回，也会恢复各 Tab 原来的页面和滚动位置。旧会话中的独立复习 Tab 会自动合并到训练。

## 成长计划

- 每周 3～4 小时，20 周主线加 4 周缓冲，共 24 个周任务；不按日期催促或自动判定完成。
- 四类案例为玩法与关卡工具、Unity 系统与框架、真机性能与稳定性，以及插件与版本交付。
- 任务与案例支持状态、实践草稿，以及现有笔记和题目的关联。
- 输入自动保存到本机。失败时保留页面内容并提供重试，较早的异步写入不会覆盖最新输入。

计划蓝图随应用公开，个人填写的实践记录、案例草稿和关联关系只保存在当前浏览器，不进入网站源码或公开页面。

## 存储与兼容

- IndexedDB 从第 1 版升级到第 2 版，新增 `planRecords`，保留原有 `records`。
- 备份从格式 2 升级到格式 3，包含学习记录与计划／案例的状态、草稿、笔记／题目 ID 关联。
- 支持格式 1、2 导入。旧备份没有计划数据，不清除已有计划。
- 导入前完整校验，并在同一事务中按更新时间合并两类记录；无效备份不会造成部分导入。
- 未识别的未来内容 ID 会保留。计划草稿只作为文本展示，不作为 HTML 执行。
