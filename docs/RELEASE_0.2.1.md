# 0.2.1 — 手机多级页面与 Tab 导航

修复从详情切换 Tab 后回到列表的问题。四个 Tab 分别保留当前页面，详情具有独立地址、返回入口和手机标题栏；笔记与题目之间可以继续进入下一层。

- 从搜索、复习进入详情，仍属于原来的 Tab，返回到真实来源。
- 切换 Tab 保留阅读位置、题目答案展开状态；返回列表保留筛选、搜索词和滚动位置。
- 支持浏览器返回、前进，直达详情时提供返回列表的入口。
- 当前浏览器标签页刷新时恢复页面层级。页面状态使用 sessionStorage，关闭标签页后不保证继续保留；学习记录继续由原有持久存储保存。
- 手机详情使用固定返回栏和轻量转场，遵循系统减少动态效果的设置。
