# 笔记库结构改造验证

> 本文保留结构规划 / 本地验证阶段的记录。当前0.2.0版本的内容范围与发布检查见[发布说明](RELEASE_0.2.0.md)。

日期：2026-10-22。状态：本地实现完成，未提交、推送或发布；10 篇正文整理试点尚未开始。

## 已实现

- 默认首页为独立笔记库，移出面试热身、面试数量与掌握进度。
- 桌面侧栏、手机底部均保留笔记库、面试练习、我的复习、搜索四个入口；手机顶部可进入设置与备份。
- 笔记按稳定主题 ID / 子分类 ID 归位，类型、标签与收藏独立筛选；只显示已有内容的分类。
- 搜索分别显示笔记与题目及其数量。从练习进入默认搜索题目，从笔记和其他区域进入默认搜索笔记。
- 复习区分笔记 / 题目、待复习 / 已完成，支持主动加入、完成、再次复习和移出。
- 收藏或阅读普通笔记不创建复习任务；题目“不会 / 模糊”自评加入待巩固，“掌握”完成已加入的任务。完成单次复习不会擅自改变题目自评。
- 现有数据库无需清空；缺少新字段时，旧薄弱题目恢复到待巩固，普通笔记保持未加入。显式移出的题目不会因刷新再次入队。
- 导出备份为 schemaVersion 2，导入同时接受版本 1 和 2，保留修改时间、收藏、阅读位置和掌握程度。版本 1 导入时补齐复习状态。未知版本或无效状态仍整份拒绝。
- 允许未核验内容与真实个人记录署名；外部来源继续要求 HTTPS。导入或图片检查日期不视为内容核验日期。

## 浏览器验证

在本机预览完成以下交互：

- 390 px 手机底部四个入口显示正常；320 px 复习和设置页无水平溢出。
- 主题 / 子分类 / 类型 / 标签组合筛选后能打开原文章链接。
- 收藏笔记后复习区仍为空；主动加入后刷新，任务保留；完成后进入已完成列表。
- 笔记与面试题搜索结果切换，空结果提示，以及从练习进入默认搜索题目。
- 原题目路径可以查看答案、自评，并在复习区的题目页找到。
- 设置与备份入口可用，偏好与导入导出控件可见。
- 本地旧构建出现更新提示后，点击“保存进度并更新”，笔记收藏与题目自评仍保留；从练习进入复习会定位到待复习题目。

隔离样本位于 `.artifacts/structure-sample/`，不进入正式内容目录：

- 使用此前官方 Word 导出的 VSCode 笔记和嵌入 PNG，验证“工程工具 / 编辑器 / 操作指南”分类。
