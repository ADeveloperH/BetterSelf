# Android 手机测试步骤

测试地址：[BetterSelf](https://adeveloperh.github.io/BetterSelf/)。

用户选择手机自带浏览器。使用该浏览器打开完整 HTTPS 地址，按下面顺序体验。

2026 年 10 月 22 日，用户已确认手机访问、桌面入口、断网打开和重开后的题目标记保留。桌面启动仍显示浏览器地址栏，尚未验证为独立窗口安装。下次内容发布时继续检查更新及历史学习记录保留；以下步骤也可用于更换浏览器后的复测。

## 阅读与练习

1. 首页进入 C# 示例笔记，试用字号调整、目录跳转和收藏。
2. 返回首页，再次进入文章，查看阅读进度是否恢复。
3. 进入“面试练习”，先思考问题，再展开答案。
4. 把一道题标记为“模糊”，在“我的复习”的待巩固列表中找到它。
5. 关闭页面并重新打开，确认掌握程度和收藏仍然保留。

## 添加到桌面

1. 查看浏览器菜单中的“安装应用”或“添加到桌面”。
2. 按浏览器提供的操作完成安装或添加。
3. 点击桌面的 BetterSelf 图标，检查启动、底部导航和返回操作。

安装能力与入口取决于浏览器。“添加快捷方式”也可能只创建一个浏览器入口，是否使用独立窗口以实际表现为准。若找不到入口，记录浏览器名称、版本和手机系统版本，再核对对应操作。

## 离线使用

1. 联网打开网站，等待页面顶部显示“离线已就绪”。
2. 关闭网络，再从桌面或原浏览器重新打开。
3. 阅读笔记，查看答案，修改一道题的掌握程度。
4. 关闭后重新打开，确认离线保存的记录仍然保留。
5. 恢复网络。

当前演示内容较小，会随应用整体缓存。离线阅读能力以顶部准备完成的状态为准。

## 备份与后续更新

在“我的复习”导出备份，得到一个 JSON 文件。在另一浏览器打开网站，使用“导入备份”，预览记录并确认合并。

后续发布新版本时，应用会提示更新。选择“保存进度并更新”，检查新内容以及原有收藏、自评和阅读进度。

学习记录按浏览器与网站地址分别保存。电脑本地演示中的记录，可通过备份迁移到正式网站。
