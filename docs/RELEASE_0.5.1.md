# 0.5.1：手机表格横向滑动

日期：2026-10-26。本版修复宽表格在部分 Android 浏览器中显示裁切、但无法左右滑动的问题。

## 改动

- Markdown 表格外增加独立的横向滚动容器，不再让 `<table>` 同时承担表格布局和滚动职责。
- 滚动容器启用 Android/iOS 触摸惯性、水平越界限制和键盘焦点；文章的上下滚动保持不变。
- 表格保留最小列宽，超出手机正文宽度时在容器内左右滑动。
- 内容测试校验每个 Markdown 表格都生成该滚动容器和无障碍标签。

## 线上验证

- [GitHub Pages 发布任务](https://github.com/ADeveloperH/BetterSelf/actions/runs/40322731497) 的测试、子路径构建、上传和发布全部成功。
- 正式站点从 0.5.0 更新到 0.5.1 后，旧的训练状态角标保留。
- 390×844 视口下，性能总览的四列表格容器宽 306 px、可横向滚动 1499 px；模拟向右操作后 `scrollLeft` 从 0 变为 800，页面宽度仍为 390 px。
