# 0.3.5：取消站外直接打开入口

日期：2026-10-26。

## 问题

Android 安装版实测确认，即使由用户在参考资料弹窗中选择“离开应用打开”，部分设备仍会进入无法可靠返回的 PWA 站外容器。目标网页位于第三方域名，BetterSelf 无法在该页面中提供返回按钮。

## 修复

- 移除“离开应用打开”，不再提供任何会直接离开 BetterSelf 的参考资料操作。
- 保留“复制链接”，用户可在普通浏览器中粘贴访问原网页。
- 保留“返回笔记”，并支持 Android 返回手势关闭参考资料弹窗。
- 不改变学习记录、计划记录、案例草稿和离线缓存结构。

## 验证

- 手机视口中只显示“返回笔记”和“复制链接”。
- 点击两个操作时页面地址均保持为当前笔记。
- 正式构建使用 `/BetterSelf/` 路径验证。
