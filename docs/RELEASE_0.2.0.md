## 网站结构

手机底部依次为笔记库、面试练习、我的复习、搜索；设置与备份位于顶部。默认首页按主题、子分类、类型、标签筛选笔记。搜索将笔记与面试题分开；阅读或收藏笔记不会创建复习任务。

学习记录继续使用原站域名、数据库与稳定内容ID。旧题目自评保留，备份导出升级到版本2，仍接受版本1导入；显式移出复习的条目不会因刷新重新加入。

## 手机获取更新

打开原站地址，保持联网并刷新一次。页面提示“有新的内容与功能可以使用”时，点“保存进度并更新”。更新后首页显示“笔记库”，有10篇笔记；手机底部是上述四个入口。

若从桌面图标打开仍是旧版，先完全退出这个页面，再用同一浏览器访问原网址并刷新，等更新提示后再进入。不要清除浏览器站点数据，以保留本机收藏、自评和阅读进度。

Android真机上的本次升级、安装入口和完整断网重启仍需用户设备确认；本机浏览器验证不能替代真机验收。
