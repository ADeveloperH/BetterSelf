# 0.3.1：第二批 Android 笔记整理

日期：2026-10-26。本版从第二批 10 个 Android 候选来源中新增 2 篇整理稿，网站内容由 10 篇增加到 12 篇；5 道面试题及 0.3.0 的计划、案例和导航结构不变。

## 新增内容

- **Android Handler 消息机制：从入队到线程切换**：合并两份内容重叠的历史笔记，统一说明 Handler、Looper、MessageQueue、ThreadLocal、IdleHandler 和 HandlerThread。传统链式队列结构限定在旧实现背景，并补充 Android 17 对 targetSdk 37+ 的 MessageQueue 变化。
- **MMKV 存储机制：mmap、Protobuf 与追加写入**：整理文件映射、编码、追加、去重重写、扩容和 CRC 的关系，删除缺少设备、版本和测试方法的性能数字；与既有锁和多进程历史篇互链。

两篇均属于局部文档复核，没有做 Android 设备实验、性能基准或故障注入，因此 `verifiedAt` 继续为空。

## 候选分流

本批 10 个来源按正文实际内容处理：两份 Handler 合并为一篇，一份 MMKV 独立整理；五份空正文归档，一份 LiveData 读取失败待客户端导出，一份 App 启动流程链接索引待逐项核验。所有来源仍保留在有道云笔记，没有执行重命名、移动或删除。

原始 API 响应、来源 ID、原目录和批次决策保存在被 Git 忽略的 `.artifacts/youdao-pilot/batches/02-android/`，不进入网站内容。
