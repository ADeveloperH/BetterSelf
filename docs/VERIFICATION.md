# BetterSelf 本地演示验证记录

验证日期：2026 年 10 月 22 日。

本地演示已完成。验证覆盖桌面浏览器中的实际交互与手机尺寸布局，Android 真机安装和日常网络访问尚待发布后验收。

## 自动检查

`npm test` 的 12 项检查通过，覆盖：

- 实际示例内容构建与稳定内容指纹。
- 重复内容 ID、无效文章关联、无效日期与非 HTTPS 来源拒绝。
- Markdown 原始 HTML 转义和外部链接窗口隔离。
- 中文、全角 C#、GC 与多关键字检索。
- 数据库重开后的记录保留，查看答案不改变掌握程度。
- 并发修改不同记录字段时保留双方结果。
- 跨数据库备份恢复，以及按时间合并新旧记录。
- 无效记录、重复 ID、不支持的备份版本与破损 JSON 拒绝。

`npm run build` 通过 TypeScript 检查和正式构建。生成安装清单、应用图标、服务工作线程与离线预缓存。

## 浏览器实际操作

| 检查                     | 结果                                                         |
| ------------------------ | ------------------------------------------------------------ |
| 393px 手机尺寸首页和文章 | 正文无横向溢出，代码块可独立横向滚动                         |
| 360px 题库与深色模式     | 页面无横向溢出，底部导航可用                                 |
| 430px 首页               | 页面无横向溢出                                               |
| 1440px 桌面布局          | 侧栏、内容与学习概览正常排列                                 |
| 阅读字号与收藏           | 修改字号后生效，收藏状态刷新后保留                           |
| 阅读位置                 | 通过目录跳转阅读后刷新，恢复已保存的进度                     |
| 题目自评                 | 先展开答案，再标记“模糊”；刷新后状态保留                     |
| 薄弱题列表               | “模糊”的题目进入待巩固列表                                   |
| 搜索与空结果             | GC 能查到对应问题，无结果时提供重新搜索入口                  |
| 导出备份                 | 浏览器成功下载 JSON 备份                                     |
| 导入备份                 | 展示 2 条记录预览，确认后合并；相同时间的记录保留原值        |
| 缓存使用                 | 停止本地 HTTP 服务、确认服务不可达后，页面仍可刷新并进入题库 |
| 版本更新                 | 构建本地新版后显示更新提示；确认更新后，原有自评与收藏保持   |
| 项目子路径               | `/BetterSelf/` 下文章链接可打开并刷新，浏览器无错误日志      |

手机尺寸模拟使用桌面浏览器，不能替代实际 Android 浏览器兼容性验证。缓存检查模拟的是源站不可达，实际手机断网与重开行为仍需确认。

## 实机与发布待验收

- 用户确认目标 GitHub 账号、公开仓库和免费发布后，再创建远程仓库并上传内容。
- 获得 HTTPS 测试地址后，用红米手机常用网络检查首次加载、刷新和访问稳定性。
- 确认手机浏览器名称及版本，验证安装入口、桌面图标和独立窗口启动。
- 首次缓存完成后关闭网络，重开应用并阅读、练习、保存记录。
- 手机获取后续版本时，确认收藏、自评和阅读位置保留。
- 按需要通过导出和导入，将本地演示的学习记录迁移到正式地址。
