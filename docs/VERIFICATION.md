# BetterSelf 发布与使用验证记录

验证日期：2026 年 10 月 22 日。

网站已完成首次发布。验证覆盖本地及线上桌面浏览器中的实际交互与手机尺寸布局；用户已在 Android 真机确认访问、桌面入口、断网打开和题目标记保留。手机版本更新仍待后续发布时验收。

## 自动检查

`npm test` 的 12 项检查通过，覆盖：

- 实际示例内容构建与稳定内容指纹。
- 重复内容 ID、无效文章关联、无效日期与非 HTTPS 来源拒绝。
- Markdown 原始 HTML 转义和外部链接窗口隔离。
- 中文、全角 C#、GC 与多关键字检索。
- 数据库重开后的记录保留，查看答案不改变掌握程度。
- 并发修改不同记录字段时保留双方结果。
- 跨数据库备份恢复，以及按时间合并新旧记录。
- 无效记录、重复 ID、不支持的备份版本与破损 JSON 拒绝。

`npm run build` 通过 TypeScript 检查和正式构建。生成安装清单、应用图标、服务工作线程与离线预缓存。

反馈日期：2026 年 10 月 22 日。以下结果由用户实机操作后反馈，非开发环境模拟。手机为用户填写的“红米k100pro”，使用手机自带浏览器；具体浏览器与系统版本未确认。

| 检查 | 用户反馈与结论 |
