# 0.6.0：面试追问可独立练习

日期：2026-10-27。面试题从 5 道主问题增加到 15 道：保留原 ID，补齐原有 10 条追问的答案、示例、边界和回答要点。文章仍为 21 篇，原文对照仍为 16 篇。

## 变化

- “继续追问”由不可点击的文字变为独立题目链接。进入后先思考再查看答案，每道题分别收藏、自评和进入待复习。
- 列表默认展示 5 个主问题，可按三个专题筛选，也可选择包含追问。个人收藏和自评筛选自动包含追问，避免已保存的追问被默认范围隐藏。
- 题目内容通过稳定 ID 关联，叶子题允许没有后续问题；发布校验阻止失效、重复、自引用、循环与无效父题关联。
- 直达追问补齐父题层级；从主问题进入追问再返回时保留答案展开与阅读位置，手机详情页继续隐藏底部 Tab。
- 追问使用背包、UI 刷新、采样、对象池回归和分帧任务等教学场景，未声称为真实公司面试题或个人项目成果。
