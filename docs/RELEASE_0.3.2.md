## 候选分流与隐私

两份 Addressables 来源合并为一篇，较长来源保留三条额外的问题记录。HybridCLR 来源主要是具体项目构建工具、目录、程序集与资源清单，并包含疑似客户端标识，决定仅在本地迁移档案保留，不进入公开网站。

Addressables 原文中的本机用户名、项目名、应用标识和绝对路径已用明确占位说明替换。公开内容不包含有道文件 ID、原目录、账号、API Key 或 HybridCLR 私有构建信息。三篇 MCP 响应均为纯文本，没有图片或附件引用。

原始 API 响应、来源 ID、原目录、哈希和逐项决策保存在被 Git 忽略的 `.artifacts/youdao-pilot/batches/03-unity/`，有道云中的原笔记没有被修改、移动或删除。
