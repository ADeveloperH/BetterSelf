# 0.5.0：项目实践与 Unity 性能案例

日期：2026-10-26。本版将一组真实 Unity 性能实践整理为可持续复用的项目结构。网站内容由 18 篇增加到 21 篇；5 道面试题和 16 篇公开原文对照保持不变。

## 内容

- 《Unity 移动端性能优化：诊断顺序与复用清单》区分帧率、帧间隔、切关和首次加载，并为每项方法保留证据范围。
- 《Unity Android 固定 30 FPS：一次帧同步对照实验》记录特定设备上的对照结果，不把单设备结论推广为全局配置。
- 《Unity 对象池复用：状态清理与相机跳变回归》整理所有权、旧回调、粒子边界和首帧取景的回归方法。

三篇内容都使用 `verifiedAt: null`，正文分别标明用户反馈、真机对照、代码核对、自动回归和未执行验证。

## 结构

- 私有档案使用 `.artifacts/practice/projects/<project-id>/<date>-<topic>/`，保留真实项目名、提交、路径、采样与原始证据。
- 公开文章仍按通用技术主题分类，本批放在 `Unity / 调试与性能`。
- `content/projects.yaml` 使用脱敏名称和稳定文章 ID 组成“项目实践”合集。
- 知识库新增“项目实践”集合页与合集详情页，文章继续使用独立阅读页。没有新增底部 Tab。
- 成长计划的“真机性能与稳定性”案例显示项目实践合集和三篇默认参考文章，不会覆盖用户已保存的案例草稿或自选关联。

## 校验

- 内容编译校验项目 ID、主题、文章存在性、重复关联和同主题约束。
- 导航测试覆盖“知识库 → 项目实践 → 合集 → 文章”逐层返回。
- 计划测试确认默认文章和项目合集关联都指向已发布内容。

完成发布后，手机需在“设置与备份”中点击“保存进度并更新”，版本号应变为 0.5.0。
