# 0.2.2 — 原文对照与三级阅读路径

日期：2026-10-23。

首批迁入笔记增加公开原文对照。笔记库列表是一级页面，整理稿详情是二级页面，原文对照是整理稿的下一层页面；底部四个 Tab 始终可切换，并分别保留当前层级和滚动位置。

## 原文范围

- 首批 10 份有道来源中，9 份有正文，对应 9 篇迁入整理稿；它们均提供原文对照。
- 另 1 份来源是空白笔记，只保留在本地迁移档案中，没有创建空白网站页面。
- 原有 C# 示例笔记不是有道迁入内容，不显示原文入口。
- 原文来自有道云笔记官方 Word 导出的正文与图片转换，正文未经本轮内容整理；版式可能与有道编辑器略有不同。
- 公开原文不包含有道私有来源 ID、原始目录路径、账号配置或 API Key。

## 页面与导航

- 整理稿阅读工具栏和正文末尾都提供“原文对照”入口。
- 原文页顶部返回整理稿，再返回笔记库；直达原文链接时也会自动补齐返回层级。
- 从搜索或复习打开整理稿和原文时，仍归属于原来的 Tab。
- 原文页切换底部 Tab 后，再切回会恢复原文页及滚动位置。
- 原文阅读不会覆盖整理稿的阅读进度。

## 验证

27 项自动测试通过；TypeScript 校验及 `/BetterSelf/` 正式路径构建通过。390 × 844 手机尺寸实测了整理稿入口、原文图片、三级返回、直达原文返回、Tab 往返和滚动恢复。

更新后设置页版本为 0.2.2。如仍显示旧版，点击“保存进度并更新”，无需清除网站数据。
