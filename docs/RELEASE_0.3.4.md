# 0.3.4：参考资料应用内中转

日期：2026-10-26。

> 后续 Android 安装版实机测试确认“离开应用打开”仍会进入无法可靠返回的站外容器，该入口已在 [0.3.5](RELEASE_0.3.5.md) 移除。

## 问题

Android 安装版 PWA 打开超出应用范围的网页时，会进入浏览器管理的站外页面。顶部显示的锁和域名属于浏览器安全栏，BetterSelf 无法控制该页面的返回行为。

## 修复

- 点击笔记正文或底部来源中的外部链接时，先在 BetterSelf 内显示参考资料信息。
- 弹窗提供“返回笔记”和“复制链接”，两项操作都不会离开当前笔记。
- 本版曾保留“离开应用打开”，后续实机测试证明该入口仍受 Android PWA 站外容器限制。
- 复制失败时保留可长按选择的完整地址。
- 不改变学习记录、计划记录、案例草稿和离线缓存结构。

## 验证

- 自动测试覆盖 Markdown 外链的应用内处理标记。
- 手机视口检查参考资料弹窗、复制状态和返回笔记流程。
- 正式构建使用 `/BetterSelf/` 路径验证。
