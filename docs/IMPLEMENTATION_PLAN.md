## 首版范围

最终形成四个主要入口。第一阶段先实现文章与题目两条必要路径，导航随功能完成逐步补齐。

| 入口     | 行为                                                 |
| -------- | ---------------------------------------------------- |
| 知识库   | 按专题浏览，阅读文章，跳转关联题目                   |
| 面试练习 | 先展示问题，点击后显示答案，标记“不会／模糊／掌握”   |
| 我的复习 | 按掌握程度筛选，查看收藏与最近阅读，管理学习记录备份 |
| 搜索     | 按中文、C# 关键字和标签查找文章与题目                |

样例规模为一篇短文章和 5 道关联面试题。文章和题目通过稳定 ID 关联；标题、目录或内容修改后继续保留原 ID。

第一版以本地学习和静态内容发布为边界。账号、自动跨设备同步、在线文章编辑、AI 评分及自动生成内容列入后续候选，是否加入由实际使用需求决定。

## 使用体验

- 采用简洁的中文阅读界面，主要入口位于底部导航。
- 正文默认约 17–18px，可调整字号；浅色优先，提供深色阅读模式。
- 主要触控目标至少约 44×44 CSS px，兼顾系统字体放大与屏幕底部安全区域。
- 长代码块在自身区域横向滚动，正文页面保持正常宽度。
- 文章阅读位置与题目掌握程度在退出后恢复；题目答案初始折叠。
- 所有关键字体、脚本、样式和图标随应用提供，保证缓存后可离线使用。
- 空列表、无搜索结果、下载失败和存储失败提供明确反馈。

## 技术方案

采用 Vue 3、TypeScript 和 Vite 构建客户端，通过 PWA 插件管理安装入口和服务工作线程。依赖在实施时选择互相兼容的稳定版本，并保存锁文件。

| 部分     | 方案与理由                                                                                |
| -------- | ----------------------------------------------------------------------------------------- |
| 界面     | Vue 组件与自适应样式，方便维护文章、题目与复习流程                                        |
| 文章来源 | Markdown 与元信息，便于长期整理和迁移                                                     |
| 题库来源 | YAML，答案支持多行 Markdown，便于修改代码示例                                             |
| 内容构建 | 校验内容结构、唯一 ID、关联关系和来源链接格式，生成静态内容与搜索数据                     |
| 学习记录 | IndexedDB；按稳定内容 ID 保存掌握程度、收藏、阅读位置与修改时间                           |
| 搜索     | 首版采用规范化后的文本包含匹配与标签筛选，覆盖中文及 C#、GC 等关键字                      |
| 路由     | 静态托管兼容的 hash 路由；资源和 PWA 安装范围支持项目子路径                               |
| 离线     | 当前小规模示例随应用整体缓存，并显示离线就绪状态；内容增长后再增加按专题下载              |
| 更新     | 检测新版本，提示更新；更新前保存当前进度，避免练习中途强制刷新                            |
| 备份     | 带格式版本的 JSON 导出；导入前校验并展示概况，以更新时间合并记录                          |
| 发布     | 免费 HTTPS 静态托管，GitHub Pages 作为候选；选定前以手机网络可达性和 PWA 能力验证结果为准 |

PWA 缓存与学习记录分开管理。更新或清理旧版内容缓存时保留学习记录。手机清理站点数据、更换浏览器或更换站点域名后，使用导出的备份恢复记录。

首版功能通过本地逻辑实现。AI 辅助用于开发、整理和核验内容，日常阅读与练习无需调用付费 AI 接口。

## 关键验证清单

| 场景                       | 预期                                       |
| -------------------------- | ------------------------------------------ |
| 360px 至 430px 宽度阅读    | 正文不溢出，代码块自身滚动，主要操作易点击 |
| 打开文章或题目的分享链接   | 指向正确内容，刷新后仍可打开               |
| 搜索“引用类型”“C#”“GC”     | 命中对应文章或题目，空结果提供反馈         |
| 标记后关闭并重开           | 掌握程度和收藏保持一致                     |
| 未显示答案就进入下一题     | 不自动记录为已掌握                         |
| 缓存成功后断网重开         | 应用与已下载专题可用，记录可继续保存       |
| 新版内容发布               | 出现更新入口，更新后能够看到修改           |
| 安装新版并清理旧缓存       | 收藏、掌握程度与阅读位置保留               |
| 导出后在新浏览器导入       | 对应内容的学习记录恢复                     |
| 导入无效或不支持的备份     | 展示错误，保留原有记录                     |
| 构建发现重复 ID 或无效关联 | 阻止发布并指出内容位置                     |

开发阶段重点验证内容校验、记录持久化与迁移、缓存和版本更新。视觉调整以浏览器检查为主；实际手机安装与浏览器差异由实机验收覆盖。
