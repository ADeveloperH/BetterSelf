# 0.3.3：手机端外部参考链接返回修复

日期：2026-10-26。

> 后续 Android 安装版实机测试确认此方案仍无法可靠返回，已由 [0.3.4](RELEASE_0.3.4.md) 的应用内参考资料中转取代。

## 问题

手机安装版从笔记详情打开外部参考资料时，链接会创建独立浏览上下文。Android 随后显示站外域名和锁形安全标识，但页面没有 BetterSelf 的返回按钮，用户难以回到原笔记。

锁形图标是浏览器对当前 HTTPS 站点的安全标识，不是笔记被锁定。

## 修复

- 正文中的外部链接和底部参考来源统一在当前浏览上下文打开。
- 浏览历史保留原笔记，使用 Android 系统返回键或返回手势即可回到原位置。
- 继续限制内容来源为 HTTPS，并为外部链接保留 `noreferrer`。
- 不改变笔记详情层级、底部导航、学习记录或离线缓存结构。

## 验证

- 自动测试覆盖 Markdown 外链不再生成 `target="_blank"`。
- 生产构建与 390 × 844 手机视口检查通过；后续实机测试发现站外返回行为仍由 Android 浏览器控制。
